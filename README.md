# Зеркало

Мобильный дневник честных действий: сводка, список насущных дел и короткий ежедневный отчёт по идее «Зеркала ответственности».

## Запуск

Откройте `index.html` или включите GitHub Pages для ветки `main` и папки `/ (root)`.

## Вкладки

- **Сводка** — главная цель, мотивационная доска, прогресс по сегодняшним делам.
- **Дела** — добавление, отметка, изменение и удаление задач; выполненные дела остаются в списке.
- **Зеркало** — пять коротких вопросов, автоматическое сохранение и календарь прошлых отчётов.

Нижняя навигация появляется во время прокрутки и скрывается после остановки. Данные сохраняются в `localStorage` этого браузера; резервную копию можно скачать внизу экрана.

Это самостоятельная рабочая форма по мотивам книг Дэвида Гоггинса, не официальный продукт и не дословное воспроизведение книги.
